# EdfiScripts

Simple batch scripts providing basic automation of common tasks when doing local
Ed-Fi ODS platform development. `reset_local_edfi.cmd` resets a local development
environment, and `show_edfi_repo_status.cmd` reports repository status.

Very possibly outdated now. They were last touched in February 2023, and nothing
about them has been reviewed or run since.

Windows only. Run either from a command prompt.
